## About the Project

LearnOps is a personal learning dashboard that I built to track my journey toward becoming a DevOps Engineer and Cloud Engineer.

This project is more than just a progress tracker. It represents my commitment to continuous learning, consistency, and self-improvement in technology.

The dashboard helps me manage my daily learning goals, track completed study sessions, maintain learning streaks, store notes, and visualize my progress through an interactive heatmap.
